AutoIntel AI – Intelligent Vehicle Diagnosis & Predictive Maintenance Assistant

> An AI-powered application that assists users in diagnosing vehicle faults, understanding their causes, estimating severity and repair costs, and recommending maintenance solutions using Machine Learning.

---

##  Project Overview

AutoIntel AI is an intelligent vehicle diagnostic assistant designed to simplify vehicle fault detection and preventive maintenance.

The system allows users to describe their vehicle problems in natural language or by selecting symptoms. Using Machine Learning and historical vehicle maintenance data, the application predicts the most probable fault, explains the reasoning behind the prediction, estimates severity and repair costs, and provides maintenance recommendations.

This project is being developed as part of an **Industrial Training Program**.

---

##  Problem Statement

Vehicle owners often struggle to identify the cause of mechanical problems before visiting a service center.

The objective of this project is to build an AI-powered assistant capable of:

- Understanding vehicle problems described by users.
- Predicting the most likely vehicle fault.
- Explaining why the fault occurred.
- Estimating the severity of the issue.
- Providing estimated repair costs.
- Suggesting preventive maintenance and repair recommendations.
